# backend-labs

Репозиторий содержит лабораторные работы по курсу **«Разработка серверных приложений»**.

## Структура репозитория
Особенность данного репозитория в том, что **каждая лабораторная работа вынесена в отдельную ветку**. В основной ветке (`master`) находится только общее описание.

## Технологический стек
Лабораторные написаны на Python (FastAPI).
